# 共建接收端维护

普通教师无需运行此服务。它是Python标准库HTTP/SQLite接收端，默认仅监听127.0.0.1:3020，经独立HTTPS入口转发。固定词表和告知版本与客户端共用 `references/community/`，不读取阅卷运行目录，也不连接青禾数据库。

本地合成检查：`python3 community-server/server.py --db PRIVATE_TEMP/intake.sqlite --port 3020`。生产使用专用无登录用户、独立数据目录及附带systemd单元；服务器目录路径属于部署约定，部署到其他环境时显式修改单元，不能让教师处理。运行中数据库、WAL、密钥、隧道令牌和日志一律不提交仓库。

POST `/api/v1/contributions`：只接受严格固定字段及词表；16KiB上限、固定格式版本号、每IP每分钟60次、全局每分钟300次、最多16处理线程、单连接10秒超时。协议头和内容哈希都须匹配，SQLite事务提交后才返回accepted；同key去重。异常请求不回显内容。没有公开管理或数据列表接口；`/health`只给服务状态。

最多保存100000个内容条目；180天过期清理，每小时检查。IP仅作为每次启动更换盐值的短时内存限流摘要，应用不写访问日志/正文/连接身份；前置Cloudflare和宿主系统的日志另行管理。无硬编码共享令牌，避免把公开技能变成共用密钥分发渠道；开放接口依靠严格字段、限流及容量边界。

上传只产生待审核候选。维护者通过本机受控运维通道审阅固定字段，结合合成测试判断是否改技能源码；不自动合并、不开任意命令执行或文件上传入口。公开发布新的字段范围或目的地前，同步升级告知版本并要求重新选择。

下载目录仅允许latest.json、明确版本ZIP与K12-default-rules.html三个格式，拒绝目录穿越、符号链接与大文件。ZIP由package_skill.py生成并校验SHA256后发布；旧版本可以保留为里程碑。发布前检查接收端健康、真实合成请求回执及重复key，再检查青禾健康与配置指纹未变。没有HTTPS路由和真实回执之前不得宣称上传已上线。
