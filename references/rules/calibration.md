# 学科默认规则的合成自检情境

这些是供智能体开卷前理解边界、改规则后复查的合成情境，不含真实学生资料。只有完整原题、满分及本题细则才能给出确切数值；下表不虚构跨题统一分值。自动化测试检验路由、覆盖、留档与提交保护，不能替代下列语义判断的实际校准。

| 学科／情境 | 应采用的默认判断 | 应避免的判断 |
| --- | --- | --- |
| 高中物理解答：模型错误，但代数结果碰巧等于标准值 | 核对独立正确物理关系，只给其实际达成的目标；依赖错模型的过程不因数值相同自动正确 | 因最终数字一致给全部过程分 |
| 物理填空：准确填写结果，未写过程 | 未要求过程就按所填物理量与结果评判；仍核对方向、范围及空格已给单位 | 借模型规则增设过程展示门槛 |
| 高中物理：对象与过程明确，关键关系、代入和结果齐全，省略移项 | 纯代数省略不额外惩罚，判断是否真正缺少物理关系 | 因解答短、没有写出每步移项扣分 |
| 初中物理：前一项算错，后一式应用独立且正确 | 保留其独立目标，依赖数值和物理条件另判 | 一错全错或一律沿错给满分 |
| 数学证明：与参考答案不同但完整有效的定理链 | 检查条件、推理及结论，按等价证明评价 | 只因推理顺序不同拒绝方法分 |
| 数学一般命题：只验证几个数值 | 可认有效检查或局部任务，不能替代一般证明 | 因几个例子均成立就认已证明 |
| 小学数学：正确图示法，与参考方程法不同 | 在本题目标内承认准确数量关系与结果 | 用初中代数格式要求否定小学解法 |
| 化学：方程式有错，但独立实验现象描述准确 | 反应点与观察点分开，错误依赖部分另判 | 化学式错导致整道题所有观察点归零 |
| 化学：问实验现象，只写生成物或反应原因 | 区分现象与解释，不能把原因直接当现象 | 因出现正确物质名称就给观察全分 |
| 生物：术语齐全，作用方向或层次颠倒 | 以科学意义判断，识别具体错误与独立正确关系 | 关键词齐全就视为机制完整 |
| 生物实验：处理组有差异，存在未控制混杂 | 区分数据事实、设计质量与因果推断 | 有差异就断言唯一因果机制成立 |
| 小学科学：用图和生活语言准确说明公平比较 | 认可已呈现的比较条件及观察记录 | 因未写“控制变量法”几个字判错 |
| 历史：抄出材料，未说明其如何支持论点 | 信息提取与历史解释分别判断 | 有引文就认论证完整 |
| 地理：措施通常正确，但不对应题中区域问题 | 核对空间尺度、当地条件与作用链 | 通用环保口号自动取得措施全分 |
| 道法／政治：态度用语正确，法律主体混淆 | 概念与材料应用独立核对，不评价学生品行 | 用态度或套话抵消法律适用错误 |
| 英语写作：要点表达清楚，但有局部语法错误 | 保留已经达成的内容，按实际影响评价语言维度 | 内容全部作零或忽略语言维度 |
| 教师只给总分，未提等价方法、单位或独立步骤 | 默认学科原则继续生效；agent拟定其余条件与分值并告知 | 将教师遗漏当取消，或反过来捏造教师的固定扣分 |
| 教师明确“本题不扣单位” | 只覆盖对应单位计分，原条款中方向、量纲和其他规则保留 | 整套关闭物理默认规则 |

使用时至少选与本题相关的等价方法、局部错误、只评结果、临界分和证据不足情境检查新细则。无法稳定解释的口径由主智能体重读材料、复核及终审，并按要求提醒教师；不把争议列表集中交给教师处理。
