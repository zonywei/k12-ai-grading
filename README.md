# K12 智能阅卷

面向 WorkBuddy 及支持本地 `SKILL.md`、命令执行和 Playwright 的智能体。教师说“开始阅卷”，在弹出的浏览器中亲自登录，提供原题、参考答案和已有评分细则；智能体负责环境配置、逐卷评分、低置信度复核、保存核验及报告。

**服务与下载：[grading.zonywei.com](https://grading.zonywei.com/)** · [下载信息](https://grading.zonywei.com/downloads/latest.json) · [公开源码](https://github.com/zonywei/k12-ai-grading) · [隐私与自愿共享](https://grading.zonywei.com/privacy)

## 教师开始使用

1. 下载 `k12-ai-grading` 技能ZIP，在宿主的本地技能导入入口导入；若宿主使用技能目录，将解压后的 `k12-ai-grading` 文件夹放入其技能目录，使宿主能找到 `SKILL.md`。目录位置以宿主实际设置为准。
2. 告诉智能体：“使用K12智能阅卷，开始批阅初中数学（或本次学段学科）。”首次自动配置依赖，**一次配置，长期使用**。系统密码、设备授权及平台登录由教师亲自完成。
3. 提供原题、参考答案和已有要求，只有总分或零散细则也可以。教师要求优先；缺项会先告知，再依据内置学段学科原则补拟。
4. 查看本机私密报告。低置信度卷由智能体独立复核、主智能体终审后提醒，教师可主动接管评分。

首次会询问是否自愿共享通用改进，帮助更多教师完善服务。**默认关闭，未回复不共享，不共享也能完整使用；以后可随时关闭。** 当前共享仅限固定的改进代码和合成检查类别，不发送教师原话、学校身份、原题答案、学生答卷成绩、截图报告或账号信息。自动上传无需教师登录GitHub。

## 学科与评分

小学：语文、数学、英语、科学、道德与法治。初中：语文、数学、英语、物理、化学、生物学、历史、地理、道德与法治，以及实际开设的科学。高中：语文、数学、英语、物理、化学、生物学、历史、地理、思想政治。

先确定学段，再显示该学段学科；也能直接说“初中数学”。初中、高中不要求年级，小学年级段可选。覆盖24组学段学科入口；技术、艺术、体育、劳动等不在当前范围。每题默认加载共同原则、学科原则及学段调整，教师明确冲突只覆盖相应条款。课程标准不冒充逐题扣分表，评分依据保留来源及适用条件。

## 平台与运行条件

需要 Python 3.11+、Node.js 20+ 和可运行的浏览器，依赖由智能体检查安装。适配器支持平台核验和恢复机制；每个网站的当前页面仍需首任务实测。已用合成站点验证通用操作，不能据此声称所有平台、所有宿主版本均已实测。识别与评分是否调用云端模型取决于宿主配置，不能承诺全部离线；共建关闭与宿主模型传输是两回事。

国内教师使用默认服务下载和上传通用改进，GitHub负责公开源码协作；默认服务由 Cloudflare 转发到独立接收进程，不能据此保证所有地区网络畅通。

## 开发与维护

在技能根目录运行 `npm ci`；由智能体运行 `python3 scripts/bootstrap.py --repair` 配置独立Python依赖和浏览器，再运行 `npm test`。所有测试使用合成数据或本机临时服务，不发布真实师生资料。后端维护见 [community-server/README.md](community-server/README.md)。代码及原创技能内容采用MIT许可，引用资料权利归原权利人。
